# TalentHub

TalentHub is a social media platform where people can connect based on their talents.  
It allows users to join talent-based communities, collaborate on projects, and hire people based on their unique skills.

---

## 🚀 Features

- User authentication (signup, login, logout)
- Profile creation and management
- Join and explore talent communities
- Collaborate with other users
- Hire people based on their talents
- Interactive frontend (HTML, CSS, JavaScript)
- Backend powered by Django

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Django (Python)  
- **Database:** SQLite (default, can be changed to PostgreSQL/MySQL)
